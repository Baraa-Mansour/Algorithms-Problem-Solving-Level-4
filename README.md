# Algorithms & Problem Solving Level 4

This project is a C++ practice workspace focused on advanced algorithmic and problem-solving exercises, especially date arithmetic, calendar logic, validation, and string-to-date conversion.

> Note: This project is designed for Windows-based development and uses Visual Studio project files. It also relies on Windows-specific C++ functions such as `localtime_s`, so it is intended to run on Windows. If you want to run it on another OS, you may need to replace platform-specific calls and use a compatible C++ build system.

## What this project is about

It is designed to help train and improve skills in:

- Date and time calculations
- Calendar generation and weekday logic
- Leap year and month-day validation
- Difference and overlap calculations between dates
- Age calculations and vacation planning logic
- String parsing and date formatting
- Writing structured, reusable C++ functions

## Level

This repository represents Level 4 of the learning journey.

## How to run

1. Open the solution file named `Algorithms & Problem Solving Level 4.sln` in Visual Studio.
2. Build the project.
3. Run the program using F5 or the Run button.

## Topics covered in `main.cpp`

The code in `main.cpp` includes practice on:

- Converting numbers to words in text form
- Leap year detection and year-day calculations
- Month length, hours, minutes, and seconds calculations
- Day-of-week ordering and weekday name extraction
- Printing monthly and yearly calendars
- Calculating total days from the start of the year
- Converting between total-day counts and dates
- Adding and subtracting days, weeks, months, years, decades, centuries, and millennia
- Comparing dates and detecting date order
- Checking overlap between date periods
- Validating dates and months
- Converting string dates to `stDate` and back
- Formatting dates in different patterns such as `dd/mm/yyyy`, `yyyy/dd/mm`, and `mm-dd-yyyy`
- Working with periods, vacation days, and return dates

The main goal is to practice solving algorithmic problems with structured functions and to strengthen C++ programming skills through date, calendar, and logic-based exercises.
